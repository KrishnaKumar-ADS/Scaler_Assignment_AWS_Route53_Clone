# AWS Route53 Management Console — Fullstack Clone

A production-grade, highly responsive AWS Route53 management console built with FastAPI, Next.js (App Router), Tailwind CSS, shadcn/ui, SQLite, and an OpenRouter-powered context-aware AI Assistant.

## 🚀 Setup & Installation

### Prerequisites
- **Python**: 3.10+
- **Node.js**: v18+ & `npm`

---

### 1. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Create and activate virtual environment
python -m venv venv
# On Windows PowerShell:
.\venv\Scripts\Activate.ps1
# On Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run database seed script (creates schema, demo users, hosted zones, and records)
python app/database/seed.py

# Optional: seed 50 test users with multi-tenant data
python seed_50_users.py

# Start FastAPI server
uvicorn app.main:app --reload --port 8000
```
The backend API server will run at `http://127.0.0.1:8000`. Swagger API docs are available at `http://127.0.0.1:8000/docs`.

#### Environment Variables (`backend/.env`)
```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

---

### 2. Frontend Setup

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Start Next.js development server
npm run dev
```
The application will run locally at `http://localhost:3000`.

## 🏗 Architecture Overview

```
                          ┌──────────────────────────┐
                          │   Next.js 14 Frontend    │
                          │ (App Router / Tailwind)  │
                          └─────────────┬────────────┘
                                        │ HTTP / JSON (Axios + Session Token)
                                        ▼
                          ┌──────────────────────────┐
                          │     FastAPI Backend      │
                          └──────┬────────────┬──────┘
                                 │            │
             SQLAlchemy ORM      │            │ OpenRouter API (OpenAI Client)
                                 ▼            ▼
                          ┌────────────┐  ┌─────────────────────┐
                          │ SQLite DB  │  │ AI Assistant Engine │
                          └────────────┘  └─────────────────────┘
```

The system is structured as a monorepo separating business logic and user interface:
- **Frontend**: Next.js 14 App Router with React context authentication, shadcn/ui components, dark/light theme switching, keyboard shortcuts (`Cmd+K`, `C`), responsive Route53 sidebar layout, and search/pagination controls.
- **Backend**: FastAPI with session token authentication dependencies, strict entity ownership checks, REST endpoints with full pagination/search, BIND zone import/export parser, and action audit logging.
- **AI Copilot**: Context-aware AI assistant powered by OpenRouter (`openrouter/free`), with strict server-side guardrails preventing unauthorized mutations or off-topic responses.
- **Database**: SQLite database (`backend/route53.db`) managed via SQLAlchemy ORM.

## 📊 Database Schema & Relationships

The SQLite database consists of 5 core tables connected via SQLAlchemy ORM relationships:

```
[ User ] (1) ────< (N) [ Session ]
   │
   ├─────────────< (N) [ HostedZone ] (1) ────< (N) [ DNSRecord ]
   │
   └─────────────< (N) [ AuditLog ]
```

### Table Details

1. **`users`**
   - `id`: Integer (Primary Key)
   - `email`: String (Unique, Indexed)
   - `hashed_password`: String
   - `created_at`: DateTime

2. **`sessions`**
   - `id`: Integer (Primary Key)
   - `token`: String (Unique, Indexed)
   - `user_id`: Integer (Foreign Key -> `users.id`)
   - `created_at`: DateTime
   - `expires_at`: DateTime

3. **`hosted_zones`**
   - `id`: Integer (Primary Key)
   - `user_id`: Integer (Foreign Key -> `users.id`)
   - `name`: String (Indexed)
   - `zone_type`: Enum (`PUBLIC`, `PRIVATE`)
   - `status`: Enum (`ACTIVE`, `INACTIVE`)
   - `record_count`: Integer
   - `description`: Text (Optional)
   - `created_at`: DateTime
   - `updated_at`: DateTime

4. **`dns_records`**
   - `id`: Integer (Primary Key)
   - `hosted_zone_id`: Integer (Foreign Key -> `hosted_zones.id`, CASCADE delete)
   - `name`: String (Indexed)
   - `record_type`: Enum (`A`, `AAAA`, `CNAME`, `TXT`, `MX`, `NS`, `PTR`, `SRV`, `CAA`)
   - `value`: Text
   - `ttl`: Integer (Default: 300)
   - `created_at`: DateTime
   - `updated_at`: DateTime

5. **`audit_logs`**
   - `id`: Integer (Primary Key)
   - `user_id`: Integer (Foreign Key -> `users.id`)
   - `action`: String (e.g., `CREATE_HOSTED_ZONE`, `UPDATE_DNS_RECORD`, `DELETE_HOSTED_ZONE`)
   - `entity_type`: String (e.g., `HOSTED_ZONE`, `DNS_RECORD`)
   - `entity_id`: Integer
   - `details`: Text
   - `client_info`: String
   - `timestamp`: DateTime

## 🌐 API Overview

### 1. Authentication (`/api/auth`)
- `POST /api/auth/login`: Authenticate email/password, returns session token.
- `GET /api/auth/me`: Get active user profile.
- `POST /api/auth/logout`: Invalidate session token.

### 2. Hosted Zones (`/api/hosted-zones`)
- `GET /api/hosted-zones`: List hosted zones with pagination (`page`, `limit`) and search query (`search`).
- `POST /api/hosted-zones`: Create new Public or Private Hosted Zone.
- `GET /api/hosted-zones/{zone_id}`: Fetch details for a specific zone.
- `PUT /api/hosted-zones/{zone_id}`: Edit zone description or zone type (`PUBLIC`/`PRIVATE`).
- `DELETE /api/hosted-zones/{zone_id}`: Delete zone and all associated DNS records.
- `POST /api/hosted-zones/bulk-delete`: Delete multiple zones in bulk.

### 3. DNS Records (`/api/hosted-zones/{zone_id}/records`)
- `GET /api/hosted-zones/{zone_id}/records`: List records for a zone with pagination (`page`, `limit`) and search (`search`).
- `POST /api/hosted-zones/{zone_id}/records`: Create a new DNS record (A, CNAME, TXT, MX, etc.).
- `GET /api/hosted-zones/{zone_id}/records/{record_id}`: Get specific DNS record details.
- `PUT /api/hosted-zones/{zone_id}/records/{record_id}`: Edit DNS record name, type, value, or TTL.
- `DELETE /api/hosted-zones/{zone_id}/records/{record_id}`: Delete a specific DNS record.
- `POST /api/hosted-zones/{zone_id}/records/bulk-delete`: Bulk delete selected records.

### 4. BIND Import / Export (`/api/hosted-zones/{zone_id}`)
- `POST /api/hosted-zones/{zone_id}/records/import`: Upload and parse BIND format zone files (`.db`, `.txt`, `.zone`).
- `GET /api/hosted-zones/{zone_id}/export?format=bind|json`: Export zone data in standard RFC-compliant BIND file or structured JSON.

#### Sample BIND Zone File Format
```
$ORIGIN example.com.
$TTL 3600
www             3600    IN      A       192.168.1.10
mail            7200    IN      A       192.168.1.20
_acme-challenge 300     IN      TXT     "verification-value"
```

### 5. AI Assistant (`/api/chat`)
- `POST /api/chat`: Send infrastructure query to the OpenRouter AI Assistant. Reads user's zones & records into a secure prompt snapshot for read-only troubleshooting and advice.

### 6. Analytics & Auditing (`/api/analytics`)
- `GET /api/analytics/dashboard-stats`: Get top-level dashboard overview metrics.
- `GET /api/analytics/audit-logs`: Get paginated audit logs for system administrative actions.
